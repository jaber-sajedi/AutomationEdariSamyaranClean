عالی! بیایید یک **راهنما کامل** بسازیم همراه با **نمونه فایل JSON** برای هر مرحله از فرآیند Workflow مرخصی در سیستم شما. من مرحله‌به‌مرحله توضیح می‌دهم که چه فیلدهایی لازم است و نمونه JSON مناسب هر مرحله را هم می‌گذارم.

---

## 1️⃣ ایجاد Workflow (فرآیند مرخصی)

**Endpoint:** `POST /api/Workflow/create`
**توضیح:** یک Workflow جدید ایجاد می‌کنیم، مثلا "فرآیند مرخصی".

**فیلدها:**

| فیلد        | نوع    | توضیح                              |
| ----------- | ------ | ---------------------------------- |
| name        | string | نام Workflow (مثلا "فرآیند مرخصی") |
| description | string | توضیح کوتاه درباره Workflow        |

**نمونه JSON:**

```json
{
  "name": "فرآیند مرخصی",
  "description": "فرآیند ثبت و تایید مرخصی کارمندان"
}
```

---

## 2️⃣ ایجاد WorkflowStep (مرحله‌های Workflow)

**Endpoint:** `POST /api/WorkflowStep/create`
**توضیح:** هر Workflow شامل چند مرحله است، مثلا: "درخواست مرخصی"، "تایید مدیر"، "ثبت در سیستم HR".

**فیلدها:**

| فیلد       | نوع    | توضیح                               |
| ---------- | ------ | ----------------------------------- |
| workflowId | int    | آی‌دی Workflow که مرحله برای آن است |
| name       | string | نام مرحله (مثلا "درخواست مرخصی")    |
| order      | int    | ترتیب اجرای مرحله                   |
| roleId     | int    | نقش کاربری که مرحله را انجام می‌دهد |

**نمونه JSON:**

```json
{
  "workflowId": 1,
  "name": "درخواست مرخصی",
  "order": 1,
  "roleId": 3
}
```

```json
{
  "workflowId": 1,
  "name": "تایید مدیر",
  "order": 2,
  "roleId": 2
}
```

```json
{
  "workflowId": 1,
  "name": "ثبت در سیستم HR",
  "order": 3,
  "roleId": 4
}
```

> 🔹 دقت کنید که `workflowId` باید همان ID ای باشد که از مرحله 1 برگشت داده شد.

---

## 3️⃣ شروع Workflow Instance (شروع فرآیند برای یک کاربر)

**Endpoint:** `POST /api/WorkflowInstance/start`

**فیلدها:**

| فیلد        | نوع | توضیح                                 |
| ----------- | --- | ------------------------------------- |
| workflowId  | int | آی‌دی Workflow که می‌خواهید اجرا شود  |
| initiatorId | int | آی‌دی کاربری که فرآیند را آغاز می‌کند |

**نمونه JSON:**

```json
{
  "workflowId": 1,
  "initiatorId": 101
}
```

---

## 4️⃣ گرفتن مراحل Workflow Instance

**Endpoint:** `GET /api/WorkflowInstance/steps/{instanceId}`

* این درخواست **GET** است، JSON ندارد.
* فقط `instanceId` که بعد از شروع Workflow Instance برگشت داده شد را در URL قرار دهید.
  مثال:

```
GET /api/WorkflowInstance/steps/55
```

---

## 5️⃣ تکمیل یک مرحله از Workflow

**Endpoint:** `POST /api/WorkflowExecution/complete-step`

**فیلدها:**

| فیلد                   | نوع | توضیح                                   |
| ---------------------- | --- | --------------------------------------- |
| workflowInstanceStepId | int | آی‌دی مرحله‌ای که می‌خواهید تکمیل کنید  |
| completedById          | int | آی‌دی کاربری که مرحله را انجام داده است |

**نمونه JSON:**

```json
{
  "workflowInstanceStepId": 201,
  "completedById": 101
}
```

> 🔹 `workflowInstanceStepId` از مرحله 4 گرفته می‌شود (لیست مراحل Instance).
